Editorial Tech Director 是一套专为中文科技解读、AI 热点与知识型视频设计的 AI 制片 Skill。

该skill主要提取kimi发布会呈现的视频效果与风格，建议使用nano banana生图＋omni生视频

它不只是生成文案和 Prompt，而是将复杂的信息内容转化为一套具有丝滑产品演示感的信息可视化动画系统。

通过模块化的构图与运动设计，可以快速实现：

实体物件 — 让真实设备、屏幕、文档、硬件等成为视觉主体

双栏对比 — 两个具体对象并列展示，通过连线和运动突出差异

流程卡片 — 将复杂流程拆解成连续的视觉卡片，并通过动态路径串联

深色界面 — 用深色计算窗口表现代码、数据处理、参数变化等内容

尺度扩张 — 从一个具体对象逐步扩展到多个模块，表现规模增长与复杂度提升

系统全景 — 从单个组件平滑拉远，逐步展示完整系统与组件之间的关系

每个镜头都会根据叙事功能选择合适的构图模块 + 动态模块，而不是让所有镜头套用同一种模板，从而保持整支视频的视觉统一，同时避免画面重复。

Skill 可以进一步将完整选题转化为：

选题 → 叙事 → 分镜 → 图片 Prompt → 视频 Prompt → 字幕 → 剪辑说明

并输出结构化的完整项目文件，让每个镜头都可以独立交给 AI 图像/视频模型生成。
